# Content Scheduler — legal pages

Public pages for the **Pop Girl Files Content Scheduler**, a private tool that runs locally and uploads/schedules the channel's own videos to YouTube, TikTok and Instagram.

These pages exist so the platforms' developer consoles have URLs to point at (Google OAuth consent screen, Meta app settings).

| Page | URL |
|---|---|
| Home | https://pavelbaltov.github.io/content-schedule/ |
| Privacy Policy | https://pavelbaltov.github.io/content-schedule/legal/privacy.html |
| Terms of Service | https://pavelbaltov.github.io/content-schedule/legal/terms.html |

Served by GitHub Pages from `main` / root. Edit the HTML, commit, push — the pages update in about a minute.

The app itself is not in this repo; it lives locally and its credentials (`config.json`, `tokens.json`) are gitignored.
